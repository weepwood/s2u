# 本机工作区备份与恢复

在云端同步弹窗的「备份恢复」中可导出完整本机工作区（历史和删除标记、收藏及图标/标签/顺序、深浅主题），无需登录。文件不包含 Token、Gist ID 或同步权限配置。备份 JSON 可能含私人链接，请妥善保管。

导入支持新版本工作区备份及旧 Gist 完整备份包。先校验文件（最大 8 MiB）并显示恢复预览，确认后合并到本机。保留同地址已有收藏，不替换本机图标；新收藏保持原 ID，ID 冲突或容量超限停止。历史保留原有删除标记语义，因此备份中的有效删除标记仍可能删除对应旧历史。主题默认不恢复，需要主动开启。旧包缺少可选文件时不清空对应数据。

应用恢复前暂停自动同步，保留恢复前工作区快照，可单独导出。写入失败尝试按原始业务存储值补偿回滚并重新加载，若回滚失败明确提示。localStorage 不提供跨键原子事务，多标签页并发及浏览器崩溃仍不能保证事务一致性；请在单标签页操作并先导出备份。本机恢复不直接调用云端 API；确认数据后自行同步。尚未提供强制覆盖、账号分区迁移或整份备份的自动云端恢复。
