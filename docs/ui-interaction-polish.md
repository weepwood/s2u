# UI 交互专项验收

保留原版浅深玻璃主题、三页结构与既有业务。触屏主要入口调整为 44px，输入框使用 16px 避免移动 Safari 聚焦缩放；历史删除按钮在宽屏触屏也常驻；收藏透明管理条不接收指针，但键盘聚焦可唤醒。主卡片、导航补充 WebKit 前缀，保持原色值和不支持滤镜时的回退。减少动态效果模式禁用按压缩放与悬停位移；页签扫描仅在容器增删时执行，尺寸读取按帧合并，不改变原动效曲线。

完整和纯 CSS CI 均执行 e2e/ui-polish.spec.js，保存真实浏览器的合成数据截图与尺寸、焦点断言。截图生成不是人工视觉验收；真实 iOS/WebKit 和硬件触屏仍需验证。当前不修改存储、Gist、链接协议或新增依赖，原构建预算不变。
