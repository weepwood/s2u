# 账号独立工作区（第一阶段）

原工作区使用既有键，所有历史、收藏、主题、连接配置和备份原样保留。云同步连接页可新建以 GitHub 用户名命名的独立工作区，或切换已保存工作区。新工作区从空历史、默认收藏和默认主题开始；不会复制原账号数据。当前标签页通过 sessionStorage 选择工作区，切换需重新加载，清除源和目标的会话 Token 与绑定，但保留所有持久数据。其他标签页不受切换影响。不同工作区的历史、收藏、主题、连接配置、基线、待同步标记及备份键隔离。首次正式连接要求 Token 所属用户名与工作区一致，并绑定 GitHub 数字账号 ID，避免用户名被重新注册后误用旧数据。原工作区仍保留现有的账号绑定保护。

迁移采用用户明确的备份导出/导入：在旧工作区导出 JSON，切换目标工作区，再预览合并恢复；不会自动上传或删除旧数据。导入会暂停自动同步，主题可选。请确认导出文件内没有不希望共享的链接。工作区隔离是应用层命名空间，不是加密、浏览器用户隔离或同源安全边界；同一 origin 的脚本仍可访问存储。使用独立浏览器配置保护不同真实用户的隐私。同一工作区多标签页编辑仍受 localStorage 并发限制；新标签页默认原工作区（浏览器复制标签时可能复制 sessionStorage），请检查当前工作区。暂不支持删除工作区、改名迁移、自动绑定老数据、不同账号凭据自动复用。存储空间为同 origin 共享，容量不足需先导出并整理数据。
