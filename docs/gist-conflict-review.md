# Gist 冲突差异审查

连接页展示已验证的收藏/主题冲突，分别选择整份本机、整份云端，或在有共同基线的收藏记录冲突中逐条选择。不同记录的无冲突修改保留；排序、重复目标、容量等仍由原三方合并检查。无共同基线只能显式选择整份文件。预览不显示图标 data URL，链接仅作为文本。选择只绑定当前连接、文件及本机/远端/基线快照，重试会重新拉取，任何快照变化需重新确认。所有启用文件必须通过冲突检查，才允许应用本机数据并推送。处理前保存本机工作区快照（备份恢复页可导出），远端仍先备份再 PATCH、写后复查。Gist 无原子 CAS，本机跨键修改也非原子事务；不提供逐字段合并或复杂排序编辑。不触碰旧数据格式或 Token 权限。
