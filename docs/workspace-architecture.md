# 工作台业务模块

Change.vue 只负责布局、异步面板加载、根状态、依赖装配与生命周期入口。原有 useHistory、useCommonLinks、useCloudSync、workspaceScope 仍是唯一数据和持久化入口。

- useWorkspaceSync：Gist 同步串行协调、连接、冲突、工作区选择、备份和恢复、自动同步生命周期。
- useShareRedirect：分享 Hash、协议校验、自动/手动跳转、取消定时任务与监听。
- useBookmarkActions：收藏存储操作、导入导出、原始地址/分享地址复制。
- useHistoryActions：历史删除、清空及导入确认。
- useWorkspaceNavigation：主导航方向、键盘、帮助和命令面板状态。

模块通过显式依赖接收同一组 store/ref，不改变旧存储键、数据格式、安全策略、权限、样式或网络请求。将原来的函数体迁移为主，修正在线重试判断中的正则转义错误。后续可继续把同步模块内的备份职责拆为独立模块。测试重点为现有公开跳转、键盘、收藏、工作区、同步冲突、恢复与发布子路径回归。


## 恢复模块独立

useWorkspaceRecovery 管理本机/远端备份、导入预览、恢复前快照与下载；useWorkspaceSync 负责连接、同步调度与生命周期，向恢复模块注入忙碌状态和应用远端变更的同步门禁。历史备份恢复与完整工作区恢复一致：先保存快照并暂停自动同步。原格式、工作区键和恢复的合并语义不变。


## 低频弹窗按需加载

二维码弹窗和快捷键帮助由 Vite 动态导入，首次访问才下载对应组件（帮助入口 hover/focus 时可预取）；二维码编码器继续在打开弹窗后加载。快捷启动保留同步加载，维持 Ctrl/Cmd+K 的即时响应。加载异常重试一次，失败后关闭待打开状态并提示刷新。沿用已有二维码、下载、键盘、焦点和根/子路径回归；资源收益以生产构建报告为准，不等同真实加载时间。


## 异步界面恢复
createAsyncView 统一历史、收藏、云同步、二维码、帮助及链接模板的资源入口。预取和打开共享同一个请求，加载超时 15 秒；失败显示局部恢复按钮，弹窗使用原生 modal 占位并可取消，关闭后旧请求不会重新打开视图。重试重新挂载异步组件，不自动刷新或清空输入；若浏览器缓存了失败的动态 import（例如部署替换旧 chunk），需用户保留输入后手动刷新。快捷启动仍同步加载。真实慢网及跨浏览器验收另行记录。
