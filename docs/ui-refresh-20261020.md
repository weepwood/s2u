# 工作区 UI 优化验收 · 2026-10-20

本次改动仅涉及展示、示例填入和入口可发现性。核心分享 Hash 格式、协议校验、历史记录、Gist、导入导出和 CSP 均沿用原逻辑。

## 视觉与交互

- 桌面 1440px：品牌在顶栏，标题和快捷启动入口为第一层，三等分页签和主卡片为第二层。
- 768px：标题和命令入口不能挤压，面板宽度与左右留白协调。
- 375px、320px：导航无截断，输入与复制按钮纵向排布，示例按钮自动换行，分享地址至少可阅读三行。
- 浅色和深色：使用语义色变量；卡片、文字、焦点环和禁用态必须可辨识。
- 减少动态效果：跟随 prefers-reduced-motion，新增交互无额外持续动画。

## 回归与安全

- 示例一键填入只修改当前输入框，不调用外部 Scheme，不保存历史，不自动发起云同步。
- 快捷启动按钮调用现有 CommandPalette，不另写协议校验规则。
- 二维码与「打开测试」按钮明确区分；旧 URL Hash 不变。
- 已有 Gist、历史删除 tombstone、常用链接 JSON 及图标保持原样。
- CI 执行 npm run check、Chromium 浏览器回归与 /s2u/ 子路径验证；真实 Windows/macOS/Android/iOS Scheme 唤起仍以 docs/device-qa.md 的实机检查为准。
